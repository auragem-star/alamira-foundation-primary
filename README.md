# منصة الأميرة التعليمية — التأسيس والابتدائي

مشروع Next.js كامل (واجهة + قاعدة بيانات + رفع ملفات) جاهز للرفع على Vercel.

## المكوّنات

- **Next.js 16** (App Router) + TypeScript + Tailwind
- **Prisma** + PostgreSQL لقاعدة البيانات
- **Vercel Blob** لتخزين ملفات الواجبات والحلول
- **جلسات JWT** (httpOnly cookies) لتسجيل الدخول (طالب / ولي أمر / معلم / مدير)
- **Vercel Cron** لحذف ملفات الحلول تلقائيًا بعد التصحيح (صورة: بعد يوم، نص: بعد يومين)

## خطوات النشر على Vercel

### 1. قاعدة البيانات
- من لوحة تحكم المشروع على Vercel: **Storage → Create Database → Postgres** (أو استخدم Neon/Supabase وحط الرابط في `DATABASE_URL`)
- انسخ رابط الاتصال وحطه في متغيرات البيئة باسم `DATABASE_URL`

### 2. التخزين (Vercel Blob)
- من نفس صفحة Storage: **Create → Blob**
- هيضيف تلقائيًا متغير `BLOB_READ_WRITE_TOKEN` للمشروع

### 3. متغيرات البيئة
انسخ محتوى `.env.example` وحطه في **Settings → Environment Variables** على Vercel، واملأ:
- `AUTH_SECRET`: نص سري عشوائي طويل (ممكن تولده بالأمر `openssl rand -base64 32`)
- `CRON_SECRET`: نص سري عشوائي تاني
- `SEED_ADMIN_USERNAME` / `SEED_ADMIN_PASSWORD`: بيانات أول حساب مدير (غيّرها بعد أول دخول)

### 4. تجهيز قاعدة البيانات
بعد ربط `DATABASE_URL`، شغّل محليًا (أو عن طريق Vercel CLI):
```bash
npm install
npx prisma db push      # ينشئ الجداول
npm run db:seed         # يضيف المواد الدراسية وحساب المدير الأول
```

### 5. الرفع
```bash
git push
```
أو اربط الريبو مباشرة من لوحة تحكم Vercel واضغط Deploy.

### 6. الـ Cron
ملف `vercel.json` فيه إعداد Cron شغال كل ساعة يحذف الملفات اللي عدّى معادها. Vercel هيفعّله تلقائيًا بعد النشر (متاح في الخطة المجانية بحد أقصى مرة يوميًا — لو محتاج كل ساعة فعليًا هيحتاج ترقية الخطة؛ عدّل `schedule` في `vercel.json` لو حابب تقلل التكرار لمرة يوميًا: `"0 3 * * *"`).

## بنية النظام (ملخص)

- **الطالب**: يدخل بكود، أول مرة يكتب اسمه ويحدد صفه (لو الكود مش تأسيس)، بعدين يحل واجبات ويشوف درجاته.
- **ولي الأمر**: يدخل بكود ابنه، يشوف الدرجات بس (قراءة فقط).
- **المعلم**: يدخل بكوده، يختار مادة، يرفع واجب، يصحح حلول الطلبة.
- **المدير**: يوزر وباسورد، يولّد أكواد (طلاب/معلمين)، يفعّل/يلغي تفعيل بالبحث بالاسم، يتابع درجات أي طالب بالبحث بالكود.

## ملاحظات مهمة قبل الإطلاق الفعلي

1. **غيّر بيانات المدير الافتراضية** فورًا بعد أول دخول (السكريبت `db:seed` بيستخدم قيم مبدئية لازم تتغير).
2. **حجم الملفات**: الحد الأقصى دلوقتي 5 ميجا للملف. لو حابب ضغط تلقائي للصور قبل الرفع، ده تحسين مستقبلي مقترح (مش متضاف حاليًا).
3. **المواد الدراسية**: القايمة الافتراضية في `lib/levels.ts` (`DEFAULT_SUBJECTS`) — عدّلها حسب مناهج مدرستك الفعلية قبل تشغيل `db:seed`.
4. المشروع اتبنى وما تمش اختباره بالكامل ضد قاعدة بيانات حقيقية (بيئة التطوير هنا من غير اتصال إنترنت لتحميل محرك Prisma). **لازم مبرمج يشغّله محليًا ويتأكد من كل الشاشات قبل الإطلاق الفعلي للطلبة.**
